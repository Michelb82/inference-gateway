# GW-11: Construction capability bindings

## Problem

The gateway only recognizes routing, intent classification, and translation, while the construction application also requests parameter extraction, personal-details extraction, and configure-environment inference.

## Impact

- The gateway rejects valid construction inference requests as unknown capabilities.
- A manifest containing the full construction capability set fails validation.

## Shorthand solution

Register all construction capabilities in the gateway and bind the additional inference-heavy capabilities to the existing largest local model, with the existing smaller and OpenAI fallbacks.
