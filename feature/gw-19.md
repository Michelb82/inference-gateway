# GW-19: Identify gateway instances in manifest polling

## Problem

The manager cannot distinguish gateway replicas polling for a manifest or observe which instances have contacted it.

## Impact

- Replicas cannot be tracked independently during scaling or configuration rollout.
- A rejected or unreachable manager leaves an unconfigured gateway dormant.

## Shorthand solution

Generate a random process-lifetime identifier at startup and include it and the available OS hostname in every manifest request. Document the request headers and their security and lifecycle limits.
