# GW-10: Optional Loki log sink

## Problem

Gateway logs are available only on the local stdout/debug-file sinks.

## Impact

- Operators cannot centrally query gateway logs in Loki.
- A logging backend outage must not interrupt inference traffic.

## Shorthand solution

Add a manifest-configured Loki endpoint and a logging port that mirrors structured records to Loki after a successful readiness probe while always preserving the existing local sink.
