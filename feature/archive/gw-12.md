# GW-12: Manifest support discovery and validation

## Problem

The service manager cannot know which capabilities, inference vendors, or manifest rules are supported by the running gateway build without duplicating gateway code.

## Impact

- Manager and gateway validation can drift.
- New vendors require coordinated hard-coded manager releases.
- Invalid manifests may be activated before the gateway rejects them.

## Shorthand solution

Expose dormant-safe private endpoints that describe supported capabilities/vendors and validate candidate manifests using the gateway's exact parser and resolver.
