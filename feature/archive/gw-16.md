# GW-16: Configure capability system prompts in the manifest

## Problem

Capability system prompts are compiled into the gateway and require a rebuild to change.

## Impact

- Operators cannot update default capability instructions through manifest reloads.
- Existing manifests must supply a prompt for every ranked capability binding.

## Shorthand solution

Require a nonblank system_prompt on each capability_models entry. Resolve the rank-0 prompt into the runtime registry and include it in snapshot fingerprints. Remove built-in capability prompts, move existing instructions into the sample manifest, and support named source_locale/target_locale placeholders for translation. Preserve caller override authorization and existing result parsers.
