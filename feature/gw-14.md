# GW-14: Group manifest validation by segment

## Problem

Manifest validation combines endpoint, tool, capability binding, ingress, and runtime configuration checks in one long function.

## Impact

- Segment rules and cross-segment dependencies are difficult to follow.
- Routine validation maintenance requires navigating unrelated checks.

## Shorthand solution

Extract each segment into a dedicated validation file and helper. Keep Validate as the ordered entry point, passing the validated endpoint index to capability binding validation. Preserve existing checks, error messages, and first-error order.

- `internal/configmgmt/validate.go`
- `internal/configmgmt/validate_inference_endpoint.go`
- `internal/configmgmt/validate_tools.go`
